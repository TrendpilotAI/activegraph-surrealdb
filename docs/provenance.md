# Provenance and publication boundary

This repository is intended to be a generic ActiveGraph provider. Public source,
tests, examples, and documentation must be reviewable without access to any
application repository, customer system, private contact record, or internal
credential.

## Inputs to the design

- public ActiveGraph `1.10.0` interfaces and conformance suites;
- public ActiveGraph issues and pull requests cited in the known-issue tests;
- public SurrealDB `3.2.4` and Python SDK `2.0.0` documentation/interfaces; and
- generic, synthetic examples created for this provider.

The repository imports ActiveGraph and the SurrealDB Python SDK as external
dependencies. It does not vendor their source. Dependency packages, names, and
trademarks retain their own licenses and ownership; see [NOTICE](../NOTICE).

## Excluded material

Do not contribute:

- application-specific adapters, schemas, names, paths, or architecture notes;
- customer, contact, CRM, mailbox, device, or identity data;
- production endpoints, account IDs, tokens, passwords, or environment files;
- generated bytecode, caches, database files, traces containing payloads, or
  local absolute paths; or
- code copied from a source whose license or contributor authority is unclear.

Synthetic fixtures should be obviously fictional or historical and contain no
real email address, phone number, account identifier, or source-system key.

## Contribution provenance

By submitting a contribution, authors must have the right to license it under
Apache-2.0. Reimplement behavior from public contracts and documentation; do not
paste private application code and merely rename symbols. If a change adapts
licensed upstream material, identify the source, version, license, and material
changes in the pull request and preserve any required notices.

Known-issue reproductions link their public upstream report. Those tests are
evidence of an upstream lifecycle boundary, not a claim that this provider owns
or has fixed ActiveGraph itself.

## Pre-publication check

Before every public commit or release:

1. inspect the exact staged diff, including binary and untracked files;
2. scan source, docs, examples, fixtures, and built artifacts for secrets,
   personal data, application names, and local paths;
3. confirm generated files and `.env` remain ignored;
4. verify license headers/notices for any adapted material;
5. build the sdist and wheel and inspect their complete file lists; and
6. record the commit and test evidence without embedding private payloads.
